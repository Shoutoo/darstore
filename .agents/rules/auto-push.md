# Auto Git Push on Changes

Setiap kali menyelesaikan perubahan kode atau fitur di repository ini, selalu lakukan:
1. `git add .`
2. `git commit -m "<deskripsi perubahan yang jelas>"`
3. `git push origin main`

Tujuannya agar seluruh perubahan langsung terhubung dan ter-deploy secara otomatis ke Vercel serta tersinkronisasi dengan database Supabase Cloud.
